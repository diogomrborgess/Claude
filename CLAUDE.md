# Projeto: Sites para empresas

## Objetivo
Criar sites e landing pages para empresas/negócios (clientes do Diogo).

## Como trabalhamos
- Sites construídos no **Lovable** (workspace "Diogo's Lovable", plano Pro).
- Este repo guarda o contexto, notas, briefs e checklists de cada cliente — para ser acessível no iPhone (sessão cloud) e no MacBook (Claude Code local).
- Idioma de trabalho: português (Portugal).

## Estrutura
- `clientes/<nome-do-cliente>/brief.md` — briefing, público, tom, páginas, links do projeto Lovable
- `templates/` — briefs e checklists reutilizáveis
